Explicatii

Axa X: indicatori; axa Y: data. PH este in CET/CEST. Zile lucratoare = luni–vineri; weekend = sambata–duminica. Fara ajustare pentru sarbatori legale. Preturi EUR/MWh; volume PZU MWh (tranzactionat, buy, sell; MW de 15 minute convertiti in energie si insumati pe PH); volume ID conform exportului Nord Pool; temperatura °C; fundamentale MW. Echilibrare MWh semnat: pozitiv deficit, negativ excedent. IDA si seriile de 15 minute sunt medii PH doar cu toate cele 4 valori disponibile.

DAMAS Activated reserve = activatedReserve; Volume up/down = sumQup/sumQdn. Energie MWh insumata din cele 4 sferturi ale PH; semnele sursei sunt pastrate, datele lipsa nu sunt zero.

Eroare = actual − prognoza. Sarcina reziduala ID este proxy cu consum DA (consum ID indisponibil). Import/export DA = schimburi comerciale day-ahead ENTSO-E; intervalele RO–MD lipsa sunt completate din DAMAS mdro/romd.dayAhead; Actual = fluxuri fizice. Indisponibilitati = productie, MW, nu retea. Echilibrare = volum net ENTSO-E, completat pe intervalele lipsa cu Estimated system imbalance DAMAS. Type DAMAS stabileste sensul; status PH dupa netul celor 4 sferturi. Preturile DAMAS deficit/excedent sunt medii PH in RON/MWh, estimate, nu preturi finale. Statusul este categoria zilei curente, fara calcul procentual (coduri 1 deficit, -1 excedent, 0 echilibrat).

Spread ID VWAP - PZU = ID VWAP minus PZU, in EUR/MWh, pe acelasi PH. Pozitiv: ID peste PZU; negativ: ID sub PZU. Pentru nivelul spreadului selecteaza Valoare; celelalte moduri arata schimbarea fata de ziua de referinta.

Modificare (%) = 100 × (azi − anterior) / |anterior|. Baza zero: procent nedefinit, celula goala; foloseste diferenta absoluta. Lipsa datelor nu este echivalenta cu 0. Ora repetata la schimbarea orei este exclusa din comparatie, pentru a evita un PH ambiguu.
